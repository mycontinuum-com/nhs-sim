## Choose a workplace

Open <a href="/control/">the neighbourhood map</a>. Each location opens a desktop with its apps. The map gets out of the way inside the workplace.

- Riverside Practice offers [SystemTwo](./systemtwo.mdx), [DocuMañana](./documents.mdx), and [Fax & Furious](./messaging.mdx).
- Northbank General opens [Millenni-ish EPR](./hospital.mdx).
- High Street Pharmacy opens [NoobScript](./pharmacy.mdx).
- Neighbourhood Care opens [CareBnB](./community.mdx).
- At home offers [Witherings](./home.mdx) and [patient Messages](./messaging.mdx).

One team key opens one isolated world. The portals and APIs read the same records. Use the same patient identifier across workplaces to follow a handover. Actions can schedule work, reserve capacity, or make a record visible to another service. Advance the clock to observe delayed results.

## Build an integration

Start with [your first API call](./quickstart.mdx), then use the [API reference](./api.mdx) and <a href="/docs/explorer/">interactive API explorer</a>. <a href="/api/openapi.json">OpenAPI JSON</a> is available for client generators and agents. <a href="/docs/handbook.json">The handbook JSON</a> contains the published guides with their titles, URLs, and source text.

Use [PDS and ODS FHIR APIs](./fhir.mdx) for demographics and organisations, [CIS-too](./identity.mdx) for staff sign-in, or [the legacy browser workflow](./legacy.mdx) for HTML-only document transfer.
